# Student-Management-System-
Python-based Student Management System with CRUD operations, percentage and grade calculation, and JSON file storage.
Student Management System

A beginner-friendly Student Management System developed using Python. This console-based application allows users to manage student records, calculate percentages and grades, and store student information permanently using JSON file handling.

Features

- Add new student records
- View all registered students
- Search students using roll numbers
- Update student information
- Delete student records
- Automatically calculate percentages
- Automatically assign grades
- Save records using JSON file handling
- Validate marks and user input

Technologies Used

- Python 3
- JSON
- OS Module
- VS Code

Project Structure

Student-Management-System/
│
├── main.py
├── students.json
└── README.md

Note: "students.json" is automatically created when student records are saved.

How to Run

1. Clone this repository:

git clone YOUR_REPOSITORY_URL

2. Open the project folder in VS Code.

3. Run the following command:

python main.py
